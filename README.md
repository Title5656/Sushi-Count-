# 🍣 Sushi Count 🍵

เว็บสำหรับช่วย **นับจำนวนจานซูชิและคำนวณราคาแบบง่าย ๆ**

## วิธีใช้งาน 🥢

1. เลือกจำนวนจานซูชิที่รับประทาน
2. ดูราคารวมได้ทันที
3. เช็กยอดอาหารก่อนกลับบ้านได้อย่างสบายใจ 🍱
